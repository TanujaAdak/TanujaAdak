### 🫀 [PPG Signal Quality Assessment](https://github.com/Rajkamal08/PPG-Signal-Quality-Assessment)
*July 2025 – August 2025*

An end-to-end biomedical signal processing pipeline that ingests raw PPG data, removes noise artifacts, extracts multi-domain features, and assesses signal fidelity in real time.

- **DSP Architecture**: Butterworth bandpass filters combined with **30+ statistical & morphological features**.
- **Model Performance**: Achieved **95% classification accuracy** using a Random Forest classifier deployed via **FastAPI**.
- **Mobile Integration**: Companion mobile application engineered in React Native for live signal visualization.

### 🌾 [MittiCard: Soil Health App](https://github.com/Rajkamal08/MittiCard)
*February 2026 – April 2026*

An AI-powered mobile app that scans physical ICAR Soil Health Cards with **Groq Vision OCR** and computes crop-specific fertilizer plans with localized cost estimation.

- **Agronomic Advisory**: Custom recommendation engine for **7 crops** with automated NPK deficiency detection and a 0–100 health index.
- **Backend Architecture**: Node.js/Express and PostgreSQL backend with OTP authentication and Firebase push notifications.
